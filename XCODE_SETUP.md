# Перенос проекта на Mac и сборка в Xcode

Цель — рабочие звонки. Они требуют нативного модуля `react-native-webrtc`,
которого нет и не может быть в Expo Go.

---

## 1. Перенести проект на Mac

Git remote сейчас **не настроен**, поэтому вариантов два.

**Через GitHub (рекомендую):**

На Windows:
```bash
gh repo create televo --private --source=. --push
```

На Mac:
```bash
git clone https://github.com/<твой-логин>/televo.git
cd televo
```

**Или просто скопировать папку** — на флешку, в облако, по сети. Копировать
**без** `node_modules` (она пересоздаётся) — это ~1 ГБ мусора.

## 2. Создать `.env` на Mac

`.env` намеренно не в git (там ключи). Создай его вручную в корне проекта:

```
EXPO_PUBLIC_SUPABASE_URL=https://dzoemidyjeeqzifucvpt.supabase.co
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<значение из .env на Windows>
```

Значение второй строки скопируй из `.env` на Windows — публикуемый ключ,
он безопасен для клиента.

## 3. Установить инструменты (один раз)

```bash
# Xcode — из App Store, затем принять лицензию:
sudo xcodebuild -license accept

# CocoaPods — менеджер нативных зависимостей iOS:
sudo gem install cocoapods
```

## 4. Собрать нативный проект

```bash
npm install
npx expo prebuild --platform ios --clean
```

Это создаст папку `ios/` с настоящим Xcode-проектом. `prebuild` не запускался
на Windows — генерация iOS-проекта возможна только на macOS.

`ios/` в `.gitignore`, и это правильно: папка целиком выводится из `app.json`
и `package.json`. Не коммить её и не правь в ней ничего руками — следующий
`prebuild` всё перезапишет. Всё, что нужно поменять, меняется в `app.json`.

## 5. Запустить на телефоне

```bash
open ios/Televo.xcworkspace
```

Открывать **`.xcworkspace`**, а не `.xcodeproj` — иначе не подхватятся Pod'ы.

В Xcode:
1. Выбери свой iPhone в списке устройств сверху
2. Target **Televo** → вкладка **Signing & Capabilities**
3. Поставь **Automatically manage signing** и выбери свою Apple ID в Team
   (бесплатной учётки хватает; сборка живёт 7 дней, потом пересобрать)
4. Нажми ▶️

Либо одной командой, без открытия Xcode:
```bash
npx expo run:ios --device
```

## 6. Проверить звонки

Нужны **два устройства** — звонок себе не проверить.

Что должно произойти:
- при первом звонке iOS покажет **системный запрос на микрофон**
- при видеозвонке — **запрос на камеру**
- обе стороны слышат друг друга

**Проверь и через мобильный интернет, не только Wi-Fi** — это единственное,
что реально проверяет TURN-сервер (обход NAT). На одной Wi-Fi сети звонок
может пройти напрямую и скрыть проблему.

## Если звонок не проходит

Главное преимущество Xcode — видны нативные логи. Открой консоль
(⌘⇧C) и фильтруй по `WebRTC` или `ICE`.

- **Нет запроса на микрофон** → проверь, что в `Info.plist` есть
  `NSMicrophoneUsageDescription` (генерируется из `app.json`)
- **Звонок висит на «Connecting…»** → ICE не собирает кандидатов; смотри
  логи TURN
- **Слышно только на Wi-Fi** → TURN недоступен, нужны свои TURN-креденшелы
  вместо бесплатного openrelay

## Что осталось от Expo

Ничего не потеряно. `expo run:ios` и `expo start --dev-client` работают
как раньше, QR-код тоже. Просто вместо Expo Go теперь твоя собственная
сборка — в ней работают и звонки, и push-уведомления.
